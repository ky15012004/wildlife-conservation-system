# Vietnamese Wildlife Conservation System

## Introduction

A web-based system for recognizing and searching Vietnamese wildlife species, integrated with an AI-powered conservation chatbot.

The system aims to help users identify wildlife species through images, access detailed information about animals, explore their distribution areas and conservation status, and receive advice on wildlife protection.

## Main Features

### 1. Guest

- Register a new account.
- View animal group information.
- View wildlife distribution areas.
- View wildlife conservation status.

### 2. Registered User

- Log in to the system.
- View animal group information.
- View wildlife distribution areas.
- View wildlife conservation status.
- Interact with the virtual assistant.
- Submit proposals for adding new wildlife species.
- View image recognition history.
- View submitted proposal history.

### 3. Conservation Staff

- Log in to the system.
- Review and process wildlife species proposals.
- Update personal information.
- Manage wildlife species information.
- Manage animal group information.
- Update wildlife conservation status.
- Manage wildlife distribution information.
- Interact with the virtual assistant.

### 4. Administrator

- Log in to the system.
- Manage user accounts.

### 5. Virtual Assistant

- Recognize wildlife species from uploaded images.
- Provide wildlife conservation advice.
- Recommend appropriate wildlife protection measures.

## Technologies

- **Frontend:** ReactJS
- **Backend:** Python FastAPI
- **Database:** PostgreSQL
- **AI Image Recognition:** Trained Machine Learning Model (API Integration)
- **Version Control:** Git and GitHub
